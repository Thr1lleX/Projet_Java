Agora-Énergie est un simulateur de communauté énergétique locale et de marché pair-à-pair développé en Java. Il modélise les échanges d'énergie renouvelable entre prosommateurs en intégrant les contraintes physiques du réseau local et des règles de marché. L'application propose une validation progressive de la logique métier, d'abord en mode console puis via une interface graphique JavaFX.
